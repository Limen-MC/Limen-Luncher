# Limen Launcher 3.4

Nyven 1.6 est embarqué : nouvelle interface de l’accueil, transitions, particules, boutons et curseur de volume. La confirmation du lien audio est en français et masque le jeton personnel. Les anciennes copies Nyven gérées sont sauvegardées par le système existant.

Installer aussi le correctif lobby Nyven 1.6. Les clés, l’authentification, les données Minecraft et les autres mods sont conservés. Aucun changement du bot ni du proxy requis.

Envoyer le contenu de LIMEN-Launcher/ à la racine du dépôt GitHub, puis lancer le workflow Build LIMEN. Récupérer le .exe Windows 3.4.1 produit. Le .exe n’a pas été construit ni essayé sous Windows ici.

Le dossier SITE fourni séparément permet d’activer la redirection limen-mc.fr/user/ après installation sur le site. Tant qu’elle est désactivée, le lien direct OpenAudioMc reste utilisé.
