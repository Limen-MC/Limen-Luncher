# Connexion Limen 3.3

Comptes premium : choisir Microsoft. Le serveur vérifie la session Minecraft officielle.
Comptes locaux/non-premium : entrer un pseudo (3 à 16 caractères, lettres/chiffres/_), puis un mot de passe dans Nyven en jeu. Les mots de passe ne sont jamais enregistrés dans le launcher. Un pseudo officiel requiert Microsoft.

Les comptes locaux ont une protection IP côté serveur : changement d’IP = contact staff ; à la quatrième tentative sur un autre compte depuis une IP différente, ban local de cette IP. Le mot de passe reste obligatoire.

Le ZIP serveur séparé est privé et ne doit pas aller sur GitHub. Ce dépôt contient seulement la clé publique du serveur. Le launcher installe Nyven 1.6 automatiquement et sauvegarde les anciennes versions du mod.

Après envoi des sources sur GitHub, lancer le workflow Build LIMEN et récupérer l’installateur Windows 3.4.1. Le build Windows et un essai en jeu restent à faire.
